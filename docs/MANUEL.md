# Manuel d'utilisation

## Client

1. **Se connecter** avec l'identifiant et le PIN à 6 chiffres donnés par l'administrateur. Si la machine est utilisée, un message l'indique : réessayez plus tard.
2. **Choisir** les boissons avec + et − (jamais plus que le stock affiché).
3. **Insérer des billets** (colonne « Mon wallet »). L'argent va dans votre wallet ; **la machine ne rend pas la monnaie** : ce qui n'est pas dépensé reste pour votre prochaine visite. Un billet qui ferait dépasser le plafond (100 000 Ar) est désactivé.
4. **Valider la commande** quand le message indique « Prêt ». Ne quittez pas la page pendant la distribution.
5. Le **résultat** indique ce qui a été servi ; en cas de panne, les boissons non servies sont **remboursées dans votre wallet**. Puis « Terminer » : la session se ferme (une commande par visite).

Votre session se ferme après **2 minutes sans action** (un compte à rebours est affiché). Si la connexion se coupe pendant une validation, ne recommencez pas : reconnectez-vous et ouvrez « Ma dernière commande ». Rien n'est jamais débité deux fois.

## Administrateur

- **Machine** : voir l'état ; entrer/sortir de la maintenance (obligatoire pour modifier le catalogue, expire après 15 min d'inactivité) ; fermer la session d'un client resté connecté (impossible pendant une distribution).
- **Produits** : créer (prix multiple de 100 Ar), modifier prix et nom, activer/désactiver, réapprovisionner (+), corriger le stock (±). Un changement de prix n'affecte pas les commandes passées.
- **Comptes** : créer un client (PIN à 6 chiffres, pas de suite ni de répétition), réinitialiser un PIN (déverrouille et ferme sa session).
- **Audit** : les 50 dernières actions, avec l'avant/après.
